# Captura pendente

A entrega pede uma imagem real com duas contas vendo a mesma ocorrência.

Esta pasta não contém imagem. Não foi feita uma captura, porque o aplicativo não foi executado e não há projeto Firebase configurado nesta máquina.

Quando o seu Firebase estiver ligado:

1. Rode o aplicativo no Chrome em duas janelas, com duas contas Google.
2. Na conta A, registre uma ocorrência.
3. Na conta B, espere a mesma ocorrência aparecer sem recarregar.
4. Fotografe as duas janelas juntas, com o mesmo título visível.
5. Salve o arquivo aqui, por exemplo `duas_contas.png`.

Não use print editado nem dado de exemplo no lugar dessa foto.
